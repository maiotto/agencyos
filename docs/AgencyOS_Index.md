This index is the primary entry point for all AgencyOS documentation.

The documentation is organized by domain and follows the evolution of the project from product definition through architecture, implementation, engineering governance and AI-assisted development.

# Documentation Principles

1. Documentation is part of the product.

2. Every architectural decision must be documented.

3. Every implementation must update the corresponding documentation.

4. Historical sprint documents are preserved for traceability.

5. Consolidated documentation is the official source of truth.

6. Audit documents record the historical evolution of the project and support future reconciliations.

---

# Documentation Hierarchy

When information differs between documents, the following precedence applies:

1. Audit Documentation (historical evidence)
2. Baseline Documentation (official reference)
3. Architecture Decision Records (ADRs)
4. Architecture Documentation
5. Product Documentation
6. Technical Documentation
7. Sprint Documentation
