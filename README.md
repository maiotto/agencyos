# AgencyOS

> AI Native Operating System for Creative Agencies

## Visão

AgencyOS é uma plataforma AI Native para gestão operacional de agências de produção audiovisual, integrando processos comerciais, operação, recursos, capacidade produtiva e inteligência artificial.

## Objetivos

- Centralizar toda a operação da agência
- Planejar capacidade produtiva
- Gerenciar clientes, contratos e projetos
- Automatizar processos com IA
- Evoluir para uma Agência AI Native
